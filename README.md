# 星际快递 · Star Courier

Godot 4.6.3 制作的横向 2D 像素拼装经营游戏。当前是 **2026-10-11 开发中的 v5 可玩切片**：柜台接单、真实零件组装、免费试飞、可操控配送、成本结算、夜间采购与下一天。

当前美术为生成式栅格素材组成的独立背景、人物、前景、零件和特效图层，带分层视差与整数像素放大。旧 3D 模型、Blender 工程及历史说明保留供追溯，当前游戏不显示它们。当前演示不是正式发行版；之前的 Windows 导出不能代表此版本。

**当前阶段说明：** 当前已合并保护鸟类、未来普通委托的可读航线规则，以及按实际生态事实生成的次日评价。冻结候选通过 127 次脚本测试、导入、烟测与素材检查；853 份来源前后不变。从真实第 4 天经营存档延续的实际键鼠流程完成两笔正式配送，第 8 天重启仍保留唯一收据和两条次晨评价。原生过程中的一次外部 QA 中断、已跳过的未接订单和精确报告的范围分别记录，不冒充连续完成每一天两单。当前是云端 WIP，见 [本轮检查点](docs/QA-v5-bird-readable-checkpoint.md)；较早的 [103 套件检查点](docs/QA-v5-seeded-meteor-human-checkpoint.md) 保留。

当前 `pilot-v3` 保留了已通过动感复核的真实向上穿云航线，并接入可耗尽的全功率推进、接触钻头和撞击护盾：在压缩关卡中爬升、提速，再平飞进入轨道站；背景采用无镜像的分层环绕。实际键盘完整营业日通过 43 项检查，用户已认可修正后的上升动感。后续仍在完善装配、角色和任务，不代表最终发行验收。旧 `pilot-v1` 的经营和恢复基线保留，但它的横向低速飞行动感未通过用户验收，不能拿旧片段代表新版本。

虫洞与苔光驿站的新航线已进入主游戏集成验证，使用独立保存 / 重放版本。当前通过控制器、入口前后存盘和原生键鼠正式配送 / 重启检查，侧面入口与异世界收件的实际片段已完成独立画面复核。该片段来自明确标注的第 3 天测试存档；从新店自然经营到解锁、正式交付及第 4 天重启的三天流程也已通过 84 项实际键鼠检查。详见 [虫洞切片说明](docs/wormhole-delivery-slice.md)。

## 运行

用 **Godot 4.6.3** 打开 `project.godot`，等待导入，按 F5 运行。使用 GL Compatibility 渲染器，不需要联网、账户或第三方插件。

首次游戏已有一套八零件双推进器飞行器和独立发射台。先在柜台接单，听取可跳过的短对话。客人离开后，店员和机器人一起把包裹送到装配台；这段装货也可跳过。随后可改装或试飞。正式配送会再次确认；试飞和正式配送使用相同的航线、种子和操控物理。只有正式配送结算货款和成本。

## 操作

| 场景 | 操作 |
|---|---|
| 店内 | A / D 移动，松开后短暂减速停稳；E / Enter 附近交互，Tab 菜单；接单需实际到柜台 |
| 工位 | 零件箱选择零件，左键空格安装，左键选中或拖动已有零件，右键拆卸 |
| 选中零件 | R 旋转，Delete 拆卸，Ctrl+Z 撤销装配修改 |
| 工位视角 | 中键拖动，滚轮缩放，F 看全装置 |
| 检查器 | 参数、信号 A/B、作用目标；飞行器与发射台分开编辑 |
| 配送 | W/S 或 ↑/↓ 升降；Shift 全功率推进；Space 触发接入驾驶信号的逻辑回路 |
| 暂停 | Esc 或 P 暂停/继续；失去窗口焦点会暂停并清除按键状态 |
| 对话 | 点击继续、Space / Enter 快速显示或下一句；Esc 跳过；M 开关对白拟声，可单独调节音量 |
| 装货过场 | 点击“跳过装货”，或按 Space / Enter / Esc |
| 店内小物件 | 靠近柜上黑色弹珠，E / 手柄 A 查看；Esc / B 关闭 |
| 手柄 | 左摇杆 / 十字键移动，A 附近交互，Menu 菜单；菜单与工位支持焦点操作，飞行用左摇杆升降、RB 全功率、A 主动回路 |
| 全局 | F11 窗口/全屏；设置中调整音量、减少动态、背景速度模糊、像素密度与手柄死区 |

完整手柄映射见 [输入说明](docs/controller-input.md)。当前通过的是 Godot 合成控制器事件与实际键鼠检查，尚未连接实体手柄。

重启恢复的飞行默认暂停，需要明确继续。旧自主版在途配送保留旧规则，不把旧重放静默解释成新操控。恢复旧配送时会提示，旧版的观察倍率与暂停键保持原义。

## 这一版可以玩什么

- **店内直接移动**：放松待机、起步、移动、惯性减速、停稳五种状态，共用一套距离驱动的步态。持续按住不切换跑步；反向先减速，松开后停稳。前台、装配和补给只在附近交互；点击前台会沿真实通道返回。
- **有限营业日**：每天两份委托，最多两次正式发货，同时只接一份。试飞不限；夜间采购、校准充电台，次日再开门。
- **26 种功能零件及独立货舱**：包含新增接触钻头，全部有对应的生成式 2D 图像。相邻格形成真实结构图，断裂后分成独立刚体；没有一层固定外壳掩盖拆分。
- **与组装相关的操控**：升降、巡航与姿态稳定请求分配到实际推进器。安装位置、方向、可用推力、质量、惯性、供电和功率阀共同决定效果。输入不直接修改飞行器位置或速度；没电后只能惯性滑行。
- **保留零件差异**：逻辑门、探头、延时、分离、转台、阻尼、装甲、护盾、加速器、传送等仍有各自作用。Space 是信号源，不会无条件启动所有装置；分离会切断跨结构信号。
- **地面到太空的任务进度**：新店第一天是 360 m、约 8 m 高差的屋顶配送，具有三组实体障碍门和城市前景。两次准时完整送达后，原有声誉门槛会在下一天提供轨道站订单：520 m、真实爬升约 150 m、四组上下错开的障碍，城市下降后穿云进入轨道。数字是压缩关卡计量，不表示现实入轨距离。已保存的旧订单不会被改成新的地面航线。
- **有限能源和成本**：实际推进功、云台动作、主动装置消耗连接电池的储能。正式送达后按时效、货物完整度、耗能、弹药、维修与补件结算。免费试飞只显示预计收益。
- **四类复访客人和短故事**：人类、精灵、外星人、机器人使用保存的身份与兼容配件；世界精灵和细绘半身立绘保持对应。接单、实际结算及回店有短对话，失败会收到不同回应。故事节点与唯一结算账本一起保存，不额外发放奖励。
- **双人立绘与拟声**：左侧客人、右侧店员，多表情和发言强调；合成短拟声随可发音字符出现，标点空白静音。可调音量、静音、快速显示或跳过；失焦停止显示与声音，跳过不积压音效。
- **共同装货**：对话结束后，客人告别离店。店员绕过柜台，与机器人一起走到装配台；机器人搬运同一个独立包裹并装入实际货舱，店员用平板核对和确认。可随时跳过，结果与正常完成相同。装货完成持久保存；重启不重复已完成动作，保存失败不会越过发货承诺。
- **车间扩建**：收工后可支付 180、420 依次把 9×5 工位扩至 13×7、17×9，新增空间向右和向上开放。已有越界方案会保留，不能用旧图纸绕过新格子的购买条件。机器人与装货镜头跟随实际货舱。
- **次日客户留言**：正式结算只记事实，进入下一营业日后发布前一天的评价。店内可主动拿起平板，用独立小手机界面查看按日期分组的留言；保存失败不会提前发布或复制评价。保护鸟伤害只进入实际发生伤害的正式委托事实，不额外扣钱或重复结算声誉。
- **有限的路线变化与生态挑战**：新生成的普通委托有保存的种子和完整路线快照，并约束必要障碍内缘的预告与船体尺寸；旧订单不重抽。部分太空路线有有限流星。符合进度条件的新异世界委托会引入保护鸟，提前提示并留出避让通路；只有可归因于玩家的真实伤害才影响次晨评价，安全绕过不会受罚。海盗、追逐、藤蔓和喷发仍未实现。
- **可选物件调查**：工位旁柜上的黑色玻璃珠可就近查看，保留指定的简短说明；它不改变订单或收入，也不产生黑洞伤害。完整装修系统仍在后续计划。
- **可中断的表现**：机器人也响应实际提交的装配动作；搬货期间有独立行为所有权，重复修改不会抢走包裹。人物有脚部锚定的轻微待机动作，与前景分层。发射有压缩、点火与跟镜，背景速度模糊不作用于船、障碍或 UI，减少动态会关闭它。
- **清晰度选择**：自动按窗口选整数适配网格，1080p 通常为 960×540 的 2 倍，4K 为 1280×720 的 3 倍；640×360 是低密度选项。文字与交互控件按实际窗口布局，不随世界图像模糊。

升空版默认船有有限的 6000 J 电池、两具额定 28 N 推进器及 20 J 的一次发射供能。正常巡航请求 18 m/s，并以 30 N 调节请求帮助新手稳定操控。按住 Shift 时改为请求全部已启用且有能源的实际推进器输出，不再使用 22 m/s 目标或统一 30 N 上限；真实喷口、转向、质量、结构承载与能源决定加速度。松开 Shift 也不会立即刹停。结构梁按真实连接路径承受载荷，增加并联结构能分摊受力，但过载仍会断裂。升空版按实际耗能 0.025 元/J 计费；旧版在途配送仍保留原储能和 0.18 元/J 费用。持续冲刺、过重装甲或不平衡改装可能无法完成航程，失败后可免费试飞调整。接触钻头需要实际供电和前端接触，护盾最多吸收 65% 撞击损伤，并按吸收量耗电；高速冲击仍可能损坏装置。数值与实测见 [pilot-v3 说明](docs/extreme-build-slice.md)；旧协议见 [pilot-v2 说明](docs/pilot-ascent-design.md) 和 [pilot-v1 说明](docs/pilot-flight-design.md)。

## 存档与重放

游戏在 Godot 用户数据目录保存订单、唯一结算 ID、库存、方案、设置和当前在途配送。写入采用临时文件校验、有效备份、原子替换。正式发射先持久化委托；飞行中保存整数步检查点与稀疏输入时间线，恢复时按原设计、航线、种子和协议版本确定性重放。无效或不支持的在途协议会停止恢复并保留原记录，不能重复领取收益。

- Windows：通常为 `%APPDATA%/Godot/app_userdata/星际快递/`
- Linux：通常为 `~/.local/share/godot/app_userdata/星际快递/`

对正式在途配送点击中止会产生失败结算。关闭/重启并不撤销已经确认的配送承诺。

## 工程结构

- `scripts/main.gd`：游戏循环、原生输入、保存与界面衔接

- `scripts/parts.gd`：冻结的 25 种旧零件规则；`parts_expanded.gd`：新增接触钻头的扩展目录
- `scripts/simulation.gd`：保留的确定性 120 Hz 平面物理与旧版重放
- `scripts/pilot_simulation.gd`：冻结的 v1 喷口控制、操控信号与扫掠碰撞
- `scripts/pilot_ascent_simulation.gd`、`pilot_ascent_profile.gd`：v2 真实爬升、姿态、有限储能与独立版本航线
- `scripts/pilot_extreme_simulation.gd`、`pilot_extreme_profile.gd`：v3 全功率、连接载荷、钻切、有限撞击防护与按时间先后求解的扫掠碰撞
- `scripts/pilot_ground_profile.gd`：仅新订单使用的地面内容配置，不改 v3 物理协议
- `scripts/pilot_wormhole_simulation.gd`、`pilot_wormhole_profile.gd`：独立 v4 虫洞重放协议、整船口径、有限驿站储能与安全出口
- `scripts/pilot_protected_bird_simulation.gd`、`wildlife_contact_v1.gd`、`wildlife_sweep_v1.gd`：独立 v5 生态接触与首次伤害归因；旧协议物理不变
- `scripts/combined_offer_authoring_policy.gd`、`readable_offer_guard.gd`：新批次的鸟类 / 普通作者规则、已保存快照和严格版本验证

- `scripts/pilot_profile.gd`、`pilot_timeline.gd`：首关与默认装置、60 Hz 输入协议

- `scripts/shop_locomotion_2d.gd`、`clerk_rigid_motion_2d.gd`、`clerk_rigid_pose_2d.gd`：店内五状态移动、统一头部及距离驱动的刚性栅格步态；旧动作实现保留用于历史验证
- `scripts/courier_input.gd`：键鼠 / 手柄上下文、焦点、死区、输入释放与装配事务
- `scripts/ascent_backdrop_2d.gd`：七层无镜像升空背景、随相机 XY 视差、独立背景模糊
- `scripts/flight_backdrop_2d.gd`、`flight_cues_2d.gd`：旧协议背景与实际危险/收件功能提示
- `scripts/assembly_2d.gd`：有界机器人与装配反馈
- `scripts/game_hud.gd`、`pixel_stage.gd`：可读 HUD、模态输入与整数像素呈现
- `assets/2d_v5/`：实际运行的栅格素材；`source_art/2d_v5/`：生成原图、已留存的提示记录、裁切 / 配色 / 锚点说明和制作脚本。新流星、手机与人类部件按明确源文件清单保留；缺失的生成提示 / 调用记录不补造。
- `scripts/courier_stories.gd`、`dialogue_panel.gd`、`npc_sprite_2d.gd`：持久故事、双人立绘拟声对话及四类世界人物

- `source_art/art_direction_v4/`、`source_art/pixel_pipeline_studies/`：参考图及像素密度/调色板研究，不能当作游戏截图
- `docs/QA-v5-pilot.md`：当前验证口径与待完成项

`source_art/` 和 `assets/source/` 带 `.gdignore`，不进入运行时导入/打包。生成的 QA 影片、缓存与测试存档不进入源码 Git；复现工具保留。历史 Blender、REAPER 和原始生成图像保留可编辑源稿，不依赖临时文件路径。
