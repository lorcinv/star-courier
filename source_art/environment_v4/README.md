# Star Courier · V4 dimensional environment

New Blender geometry rebuilt against the approved `pixel-cel-shop-reference-03-4k-upscaled.png` art direction. That reference is a nearest-neighbor upscale of reference 03, not newly generated detail. No previous environment geometry, flat generated background, SVG artwork, or image textures are used in these assets.

## Files

- `shop_editable.blend`: named, separate editable shop objects, grouped by architectural function. A hidden `EXPORT` collection contains the material-merged runtime meshes.
- `create_shop.py`: reproducible shop generator. Materials are standard Principled PBR, with flat normals, one-segment real bevels and real depth.
- `city_source.blend`, `city_build.py`: editable and reproducible city/sky source; see `city_README.md`.
- `shop_manifest.json`, `city_manifest.json`: coordinates, exact sRGB palette, material names and geometry statistics.
- `validate_environment.py`, `environment_validation.json`: GLB structure, bounds, transforms, material surfaces, dependencies and SHA-256 checks.
- `audit_clearance.py`, `clearance_validation.json`: conservative source-object bounding-box audit of the complete live module envelope.
- `render_shop_proof.py`, `shop_city_preview.blend`, `shop_city_proof.png`: representative combined Blender composition study. Final visual approval belongs to the actual Godot view; the proof does not embed the runtime ship or characters.

`shop_composition_study.png` preserves the first shop-only blockout for comparison; use `shop_city_proof.png` for the current combined model.

## Rebuild

From the project root:

```sh
blender -b --python source_art/environment_v4/city_build.py
blender -b --python source_art/environment_v4/create_shop.py -- --no-render
python source_art/environment_v4/validate_environment.py
blender -b --python source_art/environment_v4/audit_clearance.py
blender -b --python source_art/environment_v4/render_shop_proof.py
```

Omit `--no-render` to render the shop-only source study after generating it. The combined proof uses CPU Cycles without denoising, because this Blender build has no OpenImageDenoise support. Small proof-render noise is not an asset texture.

## Runtime contract

- Exported files: `assets/environment_v4/shop_cutaway.glb`, `orbital_city.glb`, `flight_city.glb`, `sky_backdrop.glb`.
- Godot X is horizontal, Y is up, +Z faces the camera. All exported mesh nodes have identity transforms.
- Floor Y=0; back wall Z≈-3.25; visible front structural edge Z≈2.8. Main ceiling is Y≈8.5; upper station service architecture extends beyond the top framing.
- Counter top Y=1.30. Suggested clerk feet are at (-7.8, .25, -.3), on the runtime-owned .25-high dais. Receipt kiosk is intentionally taller and separate.
- Assembly center is (1,3,.5), cell centers X=-3..5 and Y=1..5. Platform face is Y=.46. The side cart/vise, small right storage case, rear tools and stool are placed away from the full module envelope; no static ship is embedded in the shop.
- Launch bay occupies X≈7..13. City geometry remains behind Z=-9.762 and does not intersect the shop.
- Shop exports use 30 material surfaces, with one merged mesh per palette material. Editable source retains semantic object names.
- Only `V4_WarmGlow` and `V4_CyanGlow` are emissive shop surfaces. Ordinary `V4_Cyan` is a painted surface. Palette hex values are sRGB; Blender and glTF PBR factors are correctly linearized.
- Runtime lighting should supply real directional warm light and cobalt shadow tint. Keep city/sky cast shadows off and use gentle cyan haze so depth layers stay legible. Do not remap this palette through the older green atmosphere mix.

The model includes thick floor/roof construction, deep underfloor machinery, upper station service masses, varied parcel shelves and mail containers, plants, a lowered service counter, receipt kiosk, an empty assembly platform, a raised gantry, dimensional tool wall, maintenance props, original orbital emblems, and an open launch cradle. Final game-state composition and lighting remain owned by the runtime.

## Separate decorative mechanisms

`assembly_lift.glb` and `clerk_dais.glb` are separate runtime-controlled workshop props. Their source is `workshop_mechanisms_editable.blend`, generated by `create_mechanisms.py`; see `mechanisms_README.md` for exact pivots, dimensions and scaling. They do not modify the four environment GLBs or their validated clearance.

`launch_rail.glb` and `launch_pier.glb` are separate decorative launcher supports. See `launch_supports_README.md` for their X-scaling and exact bearing-plane contract. Editable source is `launch_supports_editable.blend`; no simulation modules are embedded.
