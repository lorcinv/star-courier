# 星际快递 — Original audio source

## Music
- `workshop_loop.rpp`: **Orbital Workbench**, 40 seconds, 96 BPM, 16 bars. Warm suspended pads, rounded sub, glass arpeggio, restrained signal melody, soft electronic percussion.
- `flight_loop.rpp`: **Priority Parcel**, 32 seconds, 120 BPM, 16 bars. Related harmonic identity, faster arpeggio, stronger kick and more active bass.
- C-major-family progression: Cmaj9 / Am9 / Fmaj9 / G6, two bars each, twice through. Every synth voice, rhythm and melodic sequence was authored for this project.

Both sessions contain five individually editable, named stereo stem tracks. `compose.py` regenerates the original additive-synthesis source stems. No third-party samples, soundfonts, copied melodies or recorded performances are used. Pad and delay tails wrap across the musical cycle. REAPER applies a 5 ms boundary microfade to eliminate clicks.

## Actual REAPER use
Official Linux x86_64 REAPER 7.82 archive obtained from https://www.reaper.fm/files/7.x/reaper782_linux_x86_64.tar.xz on 2026-10-10. Installed as a portable application on the cloud workspace, not the user's computer. Used under the official fully functional 60-day evaluation, no purchase and no license bypass. See https://www.reaper.fm/download.php for current licensing information. REAPER itself is proprietary and is NOT included in this game distribution.

The RPP sessions were opened and mixed/rendered by the official REAPER executable with `-ignoreerrors -renderproject`. `renders/*.wav` are the original 24-bit 44.1 kHz stereo REAPER masters, and their BWF metadata contains `encoded_by=REAPER`. FFmpeg only encoded those final masters to the small Ogg Vorbis runtime files; it did not replace the DAW mix render. Offline rendering does not require an audio device.

To edit: open either RPP in REAPER. All WAV stems use project-relative paths. The sessions have explicit render boundaries, so no reverb tail changes the loop duration. Render produces a WAV in `../../assets/audio`; keep archival masters in `renders/`, encode runtime OGG with `ffmpeg -i input.wav -c:a libvorbis -q:a 5 output.ogg`.

## Sound effects
Original synthesized PCM WAV: `ui_select`, `module_snap`, `launch`, `delivery_success`, `warning`. Generated by `compose.py`; these short SFX were not passed through REAPER. This distinction is intentional and recorded accurately.

## Runtime integration
Enable looping for both OGG streams. Crossfade scene music over 0.7 seconds. Suggested music bus: -4 to -7 dB; SFX bus: 0 dB. Master peaks leave generous headroom. Source-art files should be excluded from runtime exports.

## Validation
`validate_audio.py` checks decoded peaks, no clipping, exact loop durations, boundary discontinuity and REAPER master metadata. `audio_validation.json` records the measured values. These are signal-analysis checks, not a claim of a human listening test.
