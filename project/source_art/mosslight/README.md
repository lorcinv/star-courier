## 原图与工程

`originals/` 保存五份完整工具输出：三张首稿，以及装饰、收件台各一次由同一内置工具完成的 alpha 清理稿。选定运行纹理与相应源图为逐字节复制，未裁切、缩放、调色、重画或按阈值修改 alpha。

`mosslight-source-layers.ora` 是可用 Krita / OpenRaster 编辑器打开的三图层工程。每个图层嵌入一张选定 PNG 的完整原始字节；图层数据已逐字节核验。工程画布为1672×1254，默认仅显示收件台，其他两层隐藏，切换图层即可检查各素材。收件台在工程预览中横向居中放置，原图本身没有变动。

分层粒度是三个素材，不是单独的岩石、玻璃或植物对象；工具没有提供更细的原生图层，不假称拥有它们。ORA片内合并预览与缩略图仅用于文件浏览，不供游戏引用。没有在图形编辑器 GUI 中实际打开工程；已检验 ZIP、XML、图层引用与原图字节完整性。封装格式依据 https://www.openraster.org/baseline/file-layout-spec.html 。

`generation-prompts.json` 记录三次初始生成的原始 prompt。`alpha-cleanup-prompts.json` 记录两次透明度清理的原始 prompt。`alpha-validation.json` 包含五份源图的尺寸、SHA256、0到255完整 alpha 直方图、包围盒和净空计数。`asset-registration.json` 是选定素材的接入数据。

源图尺寸1254×1254，旧建议512×512坐标按1254/512等比例解释：

- 接收锚点：(627, 509.4375)
- 原建议接收圈半径：225.328125 px

## 透明度的真实结果

两张透明图确有 alpha 通道，空白不是画上去的棋盘格。最终装饰约92.155%像素 alpha=0，最终收件台约85.151%像素 alpha=0。

严格的“净空区域每个像素 alpha=0”没有通过。内置工具清理后仍存在 alpha=1/255 的零星残点，不可称其全零，也未用代码清理或重解释其原始值：

- 收件台半径244.921875 px检查圆：首稿79个非零像素；选定稿6个非零像素。两版的最大 alpha 都为1，alpha ≥ 2 和 ≥ 16 均为0
- 收件台原接收半径对应的全宽双向通道：选定稿525个非零像素，最大 alpha 为1，alpha ≥ 2 和 ≥ 16 均为0
- 收件台半径400 px候选圆：选定稿55个非零像素，最大 alpha 为1，alpha ≥ 2 和 ≥ 16 均为0
- 装饰上65%画面：首稿204个非零像素；选定稿31个非零像素。两版最大 alpha 为1，alpha ≥ 2 和 ≥ 16 均为0

视觉检查：未见人物、飞船、文字或界面；浮岛彼此分开；收件台中央和上方没有可见物体封路。像素块、阶梯轮廓和蓝金工业配色与参考方向一致。最终视觉验收仍须在游戏真实缩放、过滤和背景叠加下完成；本文件不把静态素材检查写成引擎或碰撞验收通过。

## 背景与取样

两张宽图使用各自真实尺寸，不拉伸到假定的1280×720并回存。建议游戏使用 nearest 采样和稳定像素尺度。

装饰最左、最右列的 alpha 均为0，适合透明层水平循环；岛屿只出现在画面下部。远景左右边界仅构图兼容，未达到严格数学无缝，边界每通道绝对差平均4.8845、最大93。远景不能直接宣称硬拼接无缝；呈现方应使用夹取、镜像重复或经过验证的接缝处理，避免垂直重复，并在实际航程中检查接缝和边缘。
