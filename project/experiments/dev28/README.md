## 明确的工程近似

1. 切分轴取分裂核箭头方向。目标原邻接接口按邻格中心在轴上的投影分配，负侧给原件、正侧给副本，投影恰零固定给正侧；不按数组遍历决定。轴的角度不是新增GUI功能，本原型直接使用既有rot字段。
2. 两半不相连，分别继承其侧接口。其他边不变，有旁路就如实仍同体，不虚构分离。必须两侧均有接口才执行此研究操作。
3. 延用真实10J支付、质量/电量/容量/HP/强度/价格/输出/储能均分；禁止分货物和分裂核。原有电路规则决定供电，副本不借电、不新生电。
4. 保持既有分裂碰撞半径 `.43 * scale * sqrt(.5)`，不缩小碰撞半径取巧。两半中心对称放在原中心±a，a=半件碰撞半径+0.001m，形成0.002m间隙。若产生异体/障碍穿插，付费前拒绝。与继承同一刚体的固定邻件可能有圆代理重叠，沿用底层“同刚体内部不碰撞”表示；这不是有限体积切割或装配形变模拟。两圆外包络可大于原圆，不承诺缩窄。
5. 为避免对称移位凭空增加惯量，每半自转惯量取 `I_original/2 - (m_original/2)*a*a`，非正立即拒绝。未分件仍用冻结的m/6；该原型通过源外子类重建后的惯量修正保存半件值，不改冻结solver。此为保持既有集中质量模型的惯量近似，不声称真实切割材料形状已经建模。
6. 两半速度各取原刚体速度场v+ω×r，自转ω保持。未分邻件不移动；总质心、线动量、角动量和动能在浮点误差内守恒，不给分离踢力。切割支付10J但不转换成额外推进。不能靠后续免费踢开解决再碰撞。
7. 仅本实验类持有研究标记和惯量字段，未做存读、三环境版本分派、可视化或正式契约支持；不能拿该类替换生产v8保存重放。

这些结果仅证明该局部模型实现，不能据此称分裂核已有实用玩法。

## 固定一轮原第四关比较

使用原40,-560月面收件、80%完整度、8m/s限速、原陨石和流星、不改费率。统一90°/100%默认台，沿用前次审计同路点/8m/s位置反馈控制器。分级方案仅在首次100m高度通过真实输入上升沿操作一次，不调时机；预算上限440（含205默认台）。

三方案的蓝图完整写在 `test_prototype.gd::craft`：

- 原型：一电芯、三28N喷口、分裂核，440预算。切后货物侧两喷口+半电芯，工具与另一喷口在另一半电芯侧。
- 分离扣：两整电芯、三28N喷口、分离扣，435预算。切后两侧各留一块完整电芯。
- 紧凑不分级：两电芯、两28N喷口，375预算。不强迫便宜方案花满预算。

原型13.183s/100m操作确实形成两个子体。13.200s快照：载货侧6.4kg、惯量3.59170、1622.31J；另一侧3.2kg、惯量1.71296、1621.33J。与分离扣载货侧7.8kg/惯量5.77179/4411.77J相比更轻，但储能显著更少，分配收益和代价都真实存在；尚未带来本关成功策略。

不能只报告减重：原型13.225s两半再次发生0.00287HP接触，13.825s双方喷口碰撞各4.82HP；41.967s实际碰撞损失两个喷口，之后130.317s回落。分离扣方案也发生近邻再接触，42.067s碰撞毁掉剩余电芯及一个喷口，103.208s回落。分裂并不自动产生足够分离速度；两组仍受既有全局飞行输入影响，这一轮没有独立子船操作系统。不能把失败全部归因于电量，亦不能凭局部守恒通过宣称实用。

紧凑船也遭一次碰撞丢一电芯，但仍靠另一电芯完成。控制器没有为两种分级方案重新优化。此轮是确定性脚本控制完整物理航程，不是原生玩家对照，也没有正式settle账单。
