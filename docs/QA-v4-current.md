## 已知限制

- 用户已选择纯 2D 后续方向；当前块状飞行器、偏平/明亮的店内光照和临时人物表演不能代表新方向。
- 刚性 Blender 姿态枢轴不是 Spine。没有安装/购买 Spine，也没有真实 Spine 导出；许可与作者流程仍待确认。
- 全部测量运行于云端 llvmpipe 软件 GPU，没有本轮 RTX 4070 / 原生 Windows 数据。
- 像素稳定性：静止和四分之一像素相机移动一致；特意沿相机竖轴移动一像素时，960×540 比较中约 48 个像素变化，占重叠区约 0.009%，主要在阴影边缘。严格零变化标准未通过。
- 其余未重做模块仍使用早期模型；首套外观重建没有宣称全 25 件完成同等美术品质。
- 仿真是固定 120 Hz 的自定义平面系统，控制器以 60 Hz 成对推进；渲染负载过大时有有界慢速仿真提示，不无上限补帧。
- 保存、唯一结算、资源上限和效果批处理功能保留；最后新网格版本的长循环性能复测因方向调整未继续。
