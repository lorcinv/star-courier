# 店员刚性栅格动作修正

2026-10-10，Godot 4.6.3 / GL Compatibility，云端开发检查点。

## 当前状态

经独立实际画面复核的 v4 候选已接入，并完成与客户留言、装货、输入和保存的 81 个 Godot 套件聚合。当前是通过这一范围验证的开发检查点，动作仍有下文列出的打磨项。

这次是生成式 PNG 部件组成的 2D 栅格层级，不是 Spine 绑定。店内仍只有一个 155 世界像素/秒的移动档位，原有加速、惯性减速、反向、通道和输入规则均不变。没有恢复奔跑。

## 修正内容

- 头部保留同一 104×91 源像素，210 高度参考下为 91×79.625 世界像素。眨眼、半闭眼和视线变化只替换眼睛区域，头发、脸部轮廓、嘴和颈部不缩放。
- 远近腿使用独立刚性部件，股骨、小腿和鞋不随运动拉伸。支撑鞋在角色父坐标中锁定，摆脚由实际位移驱动；不能通过累加时间让原地角色继续踏步。
- 松开后捕获当时的两只脚位置。支撑脚保持固定，另一只脚用原有表现时钟在约 280 ms 内落稳，随后保留实际站姿。停稳不再切换成一个持续蹲坐的姿势。
- 长工装短裤、短露肤区和全高靴子按已认可的中立 / 平板造型匹配，避免移动到拿平板时突然换一套衣服。
- 肩部轻微呼吸不旋转整个角色；双脚不会跟着呼吸摆动。隐藏、失焦、暂停及被其他输入上下文占用时冻结，恢复时不补播离开期间的时间。
- 图层保持在人物内部的兄弟绘制顺序，共用一个店内深度，柜台仍能挡住人物下半身。平板 / 交流全姿态与部件动画一次只显示一种，不重影。

## 可编辑来源

运行文件位于 `assets/2d_v5/actors/rig_motion_v1/`，共 14 张 PNG 和一份测量清单。原始生成图保留在 `source_art/2d_v5/actors/motion_quality_staging/generated/`。

`source_art/2d_v5/actors/rig_motion_staging/build_matched_runtime_parts.py --output <目录>` 可从保留原图和测量数据重建全部运行 PNG 与清单，并逐个验证 SHA-256。技术处理只做已有像素的裁取、透明遮罩、统一采样、固定调色板和眼部注册，没有程序绘制新的角色笔画。拒绝的蹲姿、短裤版本及录像不进入运行资源。

## 剩余限制

髋膝仍能看出刚性部件转动，厚靴在交叉步中偶有轮廓挤在一起；这是下一轮小范围动作打磨项。四类客人的旧稀疏步态尚未被本次店员修正替换。平板是整幅姿态边界，不能把根位置 / 比例稳定误称为两只脚在所有姿态间完全连续。没有实体手柄或 Windows 验证结论。
