## 协议与财务边界

新在途快照保存明确的 `pilot-v1` 或 `pilot-v2`、实际设计/发射台/航线/种子、整数60Hz完成步及稀疏输入变化。每条输入驱动两次120Hz物理步。暂停、失焦、模态UI及恢复均清除未释放的驾驶键，继续必须产生新的按键。

旧自主版快照仍用旧仿真；不明协议、冲突版本、非整数步或无效时间线不结算、不覆盖原记录。完成结算后不能被随后保存重新构造成幽灵在途任务。经济账本仍是唯一授予收益的来源。

## 当前限制

用户已认可 v2 向上爬升、更快移动和非镜像随动背景的方向，并要求继续加入地面、太空、虫洞与异世界配送，以及堆叠推进器、钻头和撞击护盾。该认可不等于整款游戏或全部美术完成。当前船体仍偏模块网格形，上升航线资源面板现已移至左侧，1080p 实际截图确认右上方来袭岩石不再被该面板遮挡；人物互动和故事已集成，内容仍有限；多推进器的全功率行为已在v3中通过独立物理与原生输入验证，现有 v2 重放保持不变。v1 源代码仅保留给旧存档航班。人物目前为精灵姿态，不是 Spine 绑定。软件 GPU 证据不能替代 Windows/硬件 GPU 测试；本版尚未导出 Windows 候选，私有远端未发布本次内容。
