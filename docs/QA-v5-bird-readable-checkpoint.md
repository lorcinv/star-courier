## 冻结内容

- `pilot-v5-protected-bird` 增加一只有限生命、有限质量的保护鸟。玩家接触、实际供能的射线 / 武器与钻头才可能构成伤害；靠近、背景装饰或无关来源不产生差评。
- 每只鸟每份委托只记录一次首次实际受伤事实。试飞不产生收入或评价。正式结算保存事实，成功进入下一营业日后才发布对应评价，不另扣一笔钱或重复结算声誉。
- 未来普通种子航线使用单独的可读作者规则，约束必经障碍的内缘预告与船体像素尺寸。旧的已生成、已接和在途路线保持原快照。
- 组合作者策略只在真实新批次边界启用；特殊月面 / 虫洞任务保留各自规则。保护鸟首次引入标记、两份新订单和故事绑定与保存事务一起回滚。
- 鸟类方向提示在整个仍连接货物的装置清除鸟后退休；反向重新接近时可重新提示。受伤事实和回执历史独立保留。
