# 单一移动、人物比例与招牌验证

2026-10-10，云端 Godot 4.6.3 / GL Compatibility。当前纯 2D 开发切片；店内跑步规则已取消，飞行时的实际耗能全功率推进保持不变。

## 当前实现

- 店内仅有放松待机、启动、移动、惯性减速和停稳五种状态。满输入速度 155 世界像素/秒；持续按住不会进入第二速度档。停稳后脚步距离不再增长。
- 店员及四类客户使用中立空手待机。交流姿势由真实对话状态拥有，隐藏或离店客户不会因对话切换重新出现。兼容配件与精确原图前臂遮罩复用固定节点。
- 同视角店员的中立、移动、停步、交谈和抬头平板姿势共用同一生成图头部，按头、颈、髋和脚地标注册。210 像素角色高度下，直立头部为 91 × 79.625 世界像素；低头平板姿势保留其正常视角变化，不通过每帧外框缩放修正。
- 生成式悬挂招牌按两处吊点固定在柜台上方横梁。图像清理保持像素网格、二值透明和原始店徽；并非界面贴图。
- 柜台边的短暂停留为空手中立姿势。店员实际抵达装货工位后才拿出平板，随后读单、点击和确认均保持道具连续。

## 限制

停步换姿仍略突然，栅格腿部关节轮廓和客户的稀疏步态还可改进。规范头部矩形测量来自资源注册数据，独立视频复核才是实际画面证据。录制帧率不等于引擎帧率；自动化键鼠不等于人类手感；未连接实体手柄。当前只有云端工作，旧 Windows 候选不包含本次修正。人物是栅格姿态/部件动画，没有 Spine 绑定。

虫洞与异世界目前仍是隔离的下一阶段原型，未包含在本页的主游戏通过声明中。
