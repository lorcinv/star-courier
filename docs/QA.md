## 已知边界

1. 固定平面自定义简化物理解算，碰撞体不是模型精确轮廓；参数更适合拼装试验，不是工程计算。
2. 图形与玩法验收覆盖初始流程、主要经营操作及机制不变量；不能据此宣称任意极端装置、每种组合或每一台显卡都已验证。
3. 没有 Windows 原生运行、代码签名、安装器、手柄/触屏专门适配、多语言或云存档验证。
4. 存档在操作和结算节点保存，不恢复飞行中间帧。
5. 首版内容量为五条航线、一个蓝图槽、三级研究；不是商业规模内容量。

## 实际鼠标键盘交互

独立 X 显示器中通过原生 XTEST 输入、并以实际截图逐步核对：

1. 鼠标点击“装配车间”成功切页。
2. 选择结构梁，在空格安装：模块数从 5 增至 6，库存从 2 减至 1，质量从 8.1 增至 8.6。
3. 点击安装的结构梁并按 R：箭头由右变下，网格内模型旋转 90°。
4. 点击免费试飞：装置真实进入自动飞行。
5. 按空格：在 1.5 秒/5.7 m 暂停；再按空格后继续到 2.2 秒/9.1 m。

证据：`10`–`15` 开头的 `native` 截图。此检查与自动调用界面函数的集成测试相互补充。

最终图形测试正常退出 0，音频退出清理后没有 ObjectDB/资源泄漏或脚本错误。独立软件渲染显示器仅报告“不支持改变 VSync 模式”的驱动能力警告；正常游戏逻辑与截图未受影响。

下载体积优化后再次验证：字体子集含 1,162 个映射字符，扫描全部运行时脚本未发现缺失字符；八页实际 GUI 中中文、¥、箭头、×、角度符号均正常显示，无方框缺字。全部机制/集成测试和 Linux 导出 smoke test 重新通过。
