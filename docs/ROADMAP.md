本轮合并候选已组合种子 v1 委托、有限流星、手机外壳、恢复完整性与人类客户支撑衔接，103 套件、烟测及资源检查已在同一冻结候选完整通过，748 份来源不变。未来可读 v2 与保护鸟类不在本轮。约 60 像素镜头的首次原生出界失败已修正，初始船第二版片段通过有界复核；重件 / 适配器仍待验证，左侧余量和发射拉远仍属开放问题，继续隔离。详见 [本轮检查点](QA-v5-seeded-meteor-human-checkpoint.md)。

## 当前优先：人在店里，操作有重量

直接移动、到柜台再接单和共享手柄输入层已进入主游戏。最新用户要求已接入：取消店内奔跑，使用待机 → 启动 → 移动 → 惯性停下 → 停止的单一移动循环；默认放松站立，摆手只用于对话。头部注册、四类 NPC 中立姿势和店徽招牌已完成当前集成与原生片段检查。继续打磨停步换姿和人物关节轮廓；实体手柄验证仍未完成。

- 保留已通过的平板核单、客人离开、店员和机器人同行、同一包裹装入实际货舱与可跳过过场。本轮人类客户原速片段 05 的手部支撑、告别头部 / 服装和同一包裹移交已独立复核；后来的减少动态 / 取消修正仅有定向测试，不扩大该画面结论。
- A / D 与手柄使用同一移动速度和循环，具有短促启动、惯性制动、稳定支撑脚与转向；移除按住后跑步的阈值。飞行时的全功率推进不受此修改影响。
- 统一店员待机、移动、停步、平板和对话的头 / 颈 / 髋 / 脚地标；不能用每张图外框缩放掩盖头部比例变化。四类 NPC 同样采用自然中立待机。
- 店铺上方已加入带两处吊点与灯具的星环标识招牌；继续在不同镜头、扩建和界面下检查可见性。
- 平时自由走动，接单必须到前台。点击前台可引导店员沿通道返回，抵达后开启交互，不隔着车间远程接单。
- 手柄覆盖走动、附近交互、菜单、装配与飞行；模态框、过场、失焦和断开后清除旧输入。模拟手柄事件与实体设备实测分开记录。
- 所有路线遵守柜台和地面分层、机器人通路、扩建区域以及发射设备边界。过场结束后不因之前按住的方向键自动跑走。

## 后续店铺布置与碎片叙事

- 店铺可以布置装饰；装饰布局与订单、进度分开保存。摆放必须保留柜台、工作台、角色与机器人的可达通路，不靠外观道具改变金融或模块物理状态。
- 在角落放少量可调查的小物件，以短小、可略过的文字暗示主角不普通的过去。文字只在主动调查时出现，不恢复主界面常驻解释。
- 用户指定示例：仓库角落的一颗黑色玻璃珠。调查文本逐字保留：

“一颗微缩黑洞，易碎，千万不要弄摔着了，可能会导致一些严重的小问题。”

- 这是低调、日常感的宇宙荒诞叙事物件；当前不实现真实黑洞破坏，也不据此擅自编写宏大的主角背景。
- 本轮只接入这一颗可选调查物件。完整自由摆放、装饰购买与布局编辑仍属后续系统。
