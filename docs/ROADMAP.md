# 星际快递 · 当前开发路线

更新：2026-10-10。条目区分已有切片、当前实现与后续计划，不作为功能已完成的声明。用户要求持续自主迭代；需要购买、许可或新的账户权限时仍单独确认。

## 当前优先：人在店里，操作有重量

直接移动、到柜台再接单和共享手柄输入层已进入主游戏；当前地面集成的 59 个聚合测试套件通过。最新用户要求覆盖此前走跑方案：取消店内奔跑，使用待机 → 启动 → 移动 → 惯性停下 → 停止的单一移动循环；默认放松站立，摆手只用于对话。此动作简化、头部大小统一与 NPC 中立姿势正在后续工作中实现，本次阶段存档仍保留旧走跑行为。实体手柄验证仍未完成。

- 保留已通过的平板核单、客人离开、店员和机器人同行、同一包裹装入实际货舱与可跳过过场。
- A / D 与手柄使用同一移动速度和循环，具有短促启动、惯性制动、稳定支撑脚与转向；移除按住后跑步的阈值。飞行时的全功率推进不受此修改影响。
- 统一店员待机、移动、停步、平板和对话的头 / 颈 / 髋 / 脚地标；不能用每张图外框缩放掩盖头部比例变化。四类 NPC 同样采用自然中立待机。
- 在店铺上方增加带真实吊点与灯具的星环标识招牌；避开角色、工作台和扩建视线。新原图等待像素清理与场景验证。
- 平时自由走动，接单必须到前台。点击前台可引导店员沿通道返回，抵达后开启交互，不隔着车间远程接单。
- 手柄覆盖走动、附近交互、菜单、装配与飞行；模态框、过场、失焦和断开后清除旧输入。模拟手柄事件与实体设备实测分开记录。
- 所有路线遵守柜台和地面分层、机器人通路、扩建区域以及发射设备边界。过场结束后不因之前按住的方向键自动跑走。

## 接着完成：经营与配送的完整路线

- 地面屋顶配送已完成主游戏集成、原生输入完整营业日、暂停 / 重启与精确费用重放；改善浅色收件区对比和第二道障碍下沿的可见性。
- 保持已实现的真实向上穿云 / 轨道站配送与有限能源、全功率推进、钻头和护盾组合；强化不同拼装的可用性和反馈。
- 接入虫洞后，再扩展有独立场景和目的地故事的异世界 / 月球任务。入口 / 出口要有实际安全空间、确定性重放和不可重复结算。
- 车间升级已由正常收入在原生夜间界面购买，新增格安装 / 撤销与重启保存通过；继续验证大型装置拖动 / 旋转 / 视角、装货和发射通路及真实性能边界。

## 后续店铺布置与碎片叙事

- 店铺可以布置装饰；装饰布局与订单、进度分开保存。摆放必须保留柜台、工作台、角色与机器人的可达通路，不靠外观道具改变金融或模块物理状态。
- 在角落放少量可调查的小物件，以短小、可略过的文字暗示主角不普通的过去。文字只在主动调查时出现，不恢复主界面常驻解释。
- 用户指定示例：仓库角落的一颗黑色玻璃珠。调查文本逐字保留：

“一颗微缩黑洞，易碎，千万不要弄摔着了，可能会导致一些严重的小问题。”

- 这是低调、日常感的宇宙荒诞叙事物件；当前不实现真实黑洞破坏，也不据此擅自编写宏大的主角背景。
