# 可跳过的共同装货小过场

日期：2026-10-10。对应用户要求：对话结束后客人走开，店员与小机器人一起到装配台装货；过场可以跳过。

## 场景与输入

1. 仍使用同一外部包裹节点完成客人、柜台、机器人之间的交接。
2. 客人使用生成的告别和行走画格离开左侧，离场后不因界面重绘再次出现。
3. 机器人夹爪碰到仍被持有的包裹后才移动它。店员从柜台后走到右侧边缘，再进入前方通道。
4. 机器人先让出空间，两位角色一起走向真正的货舱。正常起始装置中店员位于机器人左边。机器人负责升举和放入；店员查看平板、点击装货确认，然后看向货舱。
5. 货物固定后才提交已装货状态，进入可编辑工坊。临时外部包裹隐藏，实际货舱显示。

仅保留“跳过装货”按钮；空格 / Esc / Enter 也可跳过。画面不显示阶段解说。结束对话的同一帧按键不会连带跳过新过场。普通 HUD 暂时隐藏，编辑、拖动和底层发射按钮不穿透。

完整播放、各阶段跳过、低动态模式和已装货存档恢复具有相同的货物、店员、机器人和离场 NPC 最终状态。自动进入工坊使用延迟调用，避免低动态模式在一次 render 中完成时发生嵌套重绘。跳过只缩短表现，不发放奖励或改变库存。

## 保存与中断

- 接单对话的已读记录先保存，再开始装货。中途退出仍保存“已接、未装货”；再次进入安全地重放未完成的场景，不重复奖励或换 NPC 外观。
- 每次订单变更递增表现代次。旧 Tween、旧完成和旧跳过无法安装另一订单的包裹。
- 写盘失败时视觉可到位，但模型仍未持久化为已装货；显示失败信息，正式发射受阻，恢复写盘后可安全重试。
- 失焦 / 隐藏时冻结场景时钟，不在返回后追赶暂停墙钟时间。失焦的跳过输入也不锁死按钮。
- 新柜台对话等待店员沿原通路走回，不瞬移穿过柜台。

## 资源与诚实范围

- 所有新增角色画格来自内置 imagegen，原始 PNG 与提示词保留。代码仅做统一尺寸、脚底 / 髋部注册、最近邻采样、调色板和透明通道清理。
- 店员行走已选用八张新生成画格，包含相反支撑腿的接触姿势，节奏按显示身高和实际步行距离调整。旧六张绘制只有三组主要步态，保留原图；旧伸手和对齐也留档，运行时辅助姿势已替换为看平板、点击和抬头确认。
- NPC 使用四张真实行走画格组成六个节奏拍，补上回程经过姿势；不能把它们称为六张独立绘制。起步和停步通过约 0.2 秒的速度变化完成，脚底始终在同一地面。
- 四类 NPC：每类四张行走、告别、站定；沿用保存的种族和兼容饰品身份，没有把店铺徽记加回客人。
- 步态由实际行走距离驱动；不以空闲立绘平移冒充步行动画，也不使用交叉淡化残影。
- 这是注册的整张精灵画格动画与已有机器人机械部件动画，没有宣称 Spine 绑定或许可。
