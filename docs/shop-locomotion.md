# 店内直接移动

2026-10-10。店员自由移动只保留一套移动循环：放松待机 → 起步 → 移动 → 惯性减速 → 停稳。没有跑步档，也没有按住时长阈值。本轮不实现店铺装修或新的可调查物件；飞行时由燃料支付的 Shift / RB 加速不受影响。

## 手感与输入边界

- `CourierInput` 负责 A/D、手柄横轴与可调死区。移动层只保留 0.001 的数值阈值，不叠加第二层手柄死区。
- 唯一目标速度为 155 世界像素/秒。A/D 与满推手柄使用同一速度；轻推按有效推量缩放。持续按住不会切换动作或增加最高速度。
- 加速为 700、松开刹车为 750、反向刹车为 1000 世界像素/秒²。反向时先减到零，再向另一侧起步；面向跟随实际移动方向。
- `idle` 是放松待机，`start` 是加速起步，`move` 是稳定移动，`inertial_stop` 是松开、减小推量或反向时的减速，`stop` 是速度归零后的 0.12 秒停稳。停稳结束回到 `idle`，新方向输入可以直接进入 `start`。
- 实际路径距离驱动画格。加速段与恒速段分别积分；换向时分别计算前后两段路程。停止、碰撞回退和界面中断不会增加虚假的脚步距离。移动模块不选择另一套跑步资源。
- 内部以不超过 1/120 秒的小步积分，同一活动帧最多处理 0.1 秒。大卡顿不会补走过去的墙钟时间。
- 进入模态界面、失焦、隐藏、装货或飞行时，默认立即清零速度与直接输入，并锁住恢复时仍按着的方向。恢复后需回到零输入，再产生新的方向输入。
- 暂停时，即使外层继续调用 `step()`，已有点击路线也不能移动。模块可保留目标，但会暂停它；回到有效上下文并收到零输入后才能从零速恢复。外层可按页面规则取消该目标。
- 仅明确获准的柜台故事自动回程可在直接输入被禁止时继续。该例外必须由世界层核实可见、聚焦、未暂停且处于自动回柜台状态后逐帧传入；不会由“存在目标”自行获得权限。

## 地面与通路

直接移动只走原画已有的甲板，不落到下方管线。柜台后脚底为 y486，柜台右端 x452 处连接到 y496 的甲板前沿，然后可以继续向右走。该 10 像素深度来自画面约 y466–500 的浅透视地面；机器人仍停在原来的 y486。

柜台后的脚保持被前景柜台遮挡；绕到实际右端后才进入前景遮挡层。前后走道用浅透视脚底占地判断，机器人水平间距 58 像素、投影深度间距 8 像素。机器人如果暂时占住转角，会阻挡进入，仍允许店员退后。不会更改机器人位置来让路。飞行器所有合法工位格都在这条前沿走道上方。

基础工坊右边界为 x864，在从 x965 开始的发射架前为完整伸出的鞋子保留 101 像素。扩建后的边界为实际车间出口向内 96 像素。自由移动及从手动位置自动回程时，相机以 1.0 的世界倍率跟随实际店员，保留像素对齐；编辑器自己的平移与缩放独立保存。

装货结束后的店员可能站在工位 y486。开始自由移动时会用一个真实的 10 像素连接步进入前沿，不瞬移。点击柜台时沿同一通路返回精确的 (276,486)，到达后才发送可打开柜台的信号。最后一小段路程也计入距离，不通过未计数的位置吸附完成。普通重绘、切换页面或订单数据刷新都不能把自由移动中的店员拉回柜台。

## 接口

世界层入口保持不变：

- `world.set_shop_input(axis, enabled)`：主控制器每帧传入已处理死区的横轴和当前上下文。
- `world.shop_interaction()`：返回附近原有入口的 id、短标签、是否可用和路径距离。柜台、工位和夜间补给各自有有限范围。
- `world.is_at_shop_counter()`：与当前页面无关，验证店员确实在柜台接待点，供接单守卫使用。
- `world.request_shop_navigation(action_id)`：已经到位时返回 true，否则开始物理行走。到达后发出 `shop_navigation_arrived(action_id)`。
- `world.cancel_shop_navigation()`：取消尚未完成的点击寻路。
- `world.shop_locomotion_snapshot()`：只读测试状态。移动模块不改变订单、包裹、库存、经济或飞行物理。

`ShopLocomotion2D` 的变化：

- `set_input(axis, enabled=true, allow_navigation=false)` 新增第三个可选参数。`enabled=false` 默认冻结整个模块；只有第三个参数为 true 且已经存在目标时，才允许自动路线移动，直接输入仍保持禁止。
- 新常量 `MOVE_SPEED=155`；`WALK_SPEED` 仅作相同值的兼容别名。移除全部 `RUN_*` 常量与按住计时。
- `snapshot().state` 只返回上述五种状态；`hold_seconds` 字段移除，改为 `stop_age`，以秒记录停止后的停稳进度。
- 新增 `snapshot().active`，表示本帧上下文是否允许模块推进；`enabled` 仍表示是否允许直接输入。`navigation_paused` 表示保留的路线是否在等待恢复授权或零输入。
- 原有位置、速度、距离、面向、路线坐标、边界、前后走道、连接步、输入锁、寻路目标、到达与碰撞字段保留。

## 验证范围

`tests/test_shop_locomotion_2d.gd` 的 96 项无窗口断言通过，使用独立 XDG 数据目录。覆盖左右方向的完整五状态、持续按住不提速、轻推、精确加减速距离、反向两段路程、停稳时脚步冻结、输入重新解锁、被暂停的点击路线、明确允许的故事回程、转角、机器人占地、基础与扩建边界、连续连接步、到达距离、30/60/120/144 Hz 一致性、单帧上限及无效数据。

世界接入由 `tests/test_shop_locomotion_world.gd` 检查实际脚底 / 遮挡、柜台接近、点击到达、模态与页面切换、隐藏 / 飞行返回、普通重绘、扩建、相机及包裹身份。共同装货、跳过、取消、新订单、隐藏、失焦与重启表现继续由 `test_cargo_transport_2d.gd` 等既有回归检查。上述核心断言不代替世界接入、图像或原生输入验收。

`docs/qa/v5/shop-locomotion-floor/` 与 `docs/qa/v5/shop-locomotion-route/` 保留此前版本的原生 Godot 渲染器地面 / 路线夹具。旧路线片段含已经取消的按住跑步规则，不能作为本轮单循环移动的验收证据。

主验证流程已另行完成实际 XTest 单速度往返、柜台返回、对话与正常装货，并检查失焦/弹窗后的旧按键隔离；证据见 [单一移动验证](QA-v5-single-movement.md)。合成控制器事件不等于实体手柄体验，画面录制帧率也不等于引擎性能。
