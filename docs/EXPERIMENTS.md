# 三个可重复的拼装实验

建议先保存当前方案，再做免费试飞。零件方向 0 为右、1 为下、2 为左、3 为上；连接目标从右侧下拉框选择。以下是理解规则的方法，不是唯一解法。

## 看见后坐力

将电磁加速器放在有电芯的主体边缘，把结构梁或另一物体紧邻它放在后侧。把加速器旋转朝后，作用目标选该物体，参数设 8。无信号输入时会尝试立即发射。试飞时看两个物体：目标被向后推出，主体向前反冲；它并不是凭空添加一段加速动画。可以把目标换成货舱，观察货舱独立轨迹。能量不足会明确报告，弹丸不会凭空消失。

## 延时后减重

做成一条没有环路的链：主体 → 分离扣 → 电芯。为分离扣指定外侧电芯。另放非门与延时器：非门不接输入，输出常真；延时器 A 接非门，参数设 2；分离扣 A 接延时器。两秒后只切断指定接点。若电芯还通过另一条结构梁连着主体，它不会掉下去，这正是结构图的效果。分离后主体质量下降，外侧电芯不能继续向主体供电。

## 扩大覆盖，也扩大风险

在侧面放装甲板，旁边装放大环，作用目标指定装甲，参数设 2。试飞碎石回廊，比较扩大前后的碰撞和攻击遮挡。装甲不会因此获得额外耐久、质量或免费能量。同样可以用缩小环压低碰撞轮廓，但它也不会减轻质量或增加推力。

## 引力果园的调试起点

默认装置在不同路线不保证通吃。为原发射台在弹簧下方相邻格再装一只弹簧，旋转向上，参数约 8，可以得到有限的向上初始冲量。该方向可以抵消部分引力偏转；重量、额外模块和日间微小路线变化仍会改变结果。先试飞，别把这个数值当成固定通关脚本。
