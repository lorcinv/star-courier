# 附件要求与实现矩阵

> 历史附件对照：以下矩阵记录早期自主配送与 3D 原型，不代表当前显示层或最新玩法约束。用户后续明确改为纯 2D 生成式像素素材、可操控高速配送，并追加共同装货、自由走动和手柄操作。现行实现以 README 为准；新增要求与未完成范围见 [开发路线](ROADMAP.md)。原有财务防重复、真实模块功能和编辑源文件保留要求继续有效。

基准：用户提供的《星际快递-立项简述.docx》《星际快递_25种零件.docx》正文。用户追加 Godot、横向侧视 3D 卡通、Blender、REAPER、新仓库、自有云电脑开发。视觉从原附件 2D 定位更新为 3D 表现，运动仍约束在侧视平面。

## 游戏循环

| 要求 | 实现 | 验证 |
|---|---|---|
| 接单→拼装→试飞→配送→结算 | 订单页、双装置车间、免费试飞、正式配送、账本、再次调整 | integration-tests.log |
| 距离、载重、时效、完整度、风险 | 5 条订单全部显示；载重改变总货物质量，时效与完整度影响收入/声望 | 集成测试、实际订单截图 |
| 发射器与飞行器分离 | 两份结构/朝向/参数/接线；发射台两秒供能准备并提供初始冲量 | 发射台能源/结构/逻辑测试 |
| 自动配送与故障分析 | 120 Hz 模拟，信号触发；事件记录显示碰撞、能源、结构、超时等 | 初始方案自动成功，无手动飞行输入 |
| 保存成熟方案 | 一个本地方案槽，保存两套结构、参数、朝向、接线与目标 | 重载参数/接线/ID 测试 |
| 白天配送、晚上经营 | 采购、三级研究、客户评价、主动结束一天 | 经营测试与图形截图 |
| 利润分项 | 收入−能源−弹药−维修−零件损失；充电台研究增加有限储能，实际用电照常计费 | 求和不变量与结算截图 |

| 有限随机变化 | 同日种子相同；换日仅小范围障碍位置、敌人节奏变化 | 同种子确定性/变化测试 |

## 全部 25 个零件

以下都可在飞行器上安装、旋转、设置参数和必要接线；发射台仅列出支持其固定准备阶段的 13 种。

| # | 零件 | 可观察行为及组合 | 主要自动测试 |
|---|---|---|---|
| 01 | 高密度电芯 | 有限储能；断开后不再跨组件供能 | 电量、分离能源、有限发射能量 |
| 02 | 功率阀 | 目标 J/s 流率；信号关闭截断供能，含持续/脉冲装置 | 阀限流、关闭、脉冲限流 |
| 03 | 推进喷口 | 朝向力、质量影响加速度、偏心力矩 | 推进/质量/转矩、起始配送 |
| 04 | 蓄能弹簧 | 先由电芯压缩储能，再分离两侧并释放守恒冲量 | 压缩、未蓄能不释放、能量上限 |
| 05 | 角度转台 | 转动指定连接模块的局部朝向 | 转台朝向与发射台旋转 |
| 06 | 结构梁 | 连接结构；惯性负载超强度损伤并断裂 | 载荷断裂、结构重建 |
| 07 | 分离扣 | 信号上升沿切断指定连接；连通分量独立运动 | 分离质量、动量、组件轨迹 |
| 08 | 缓冲器 | 耗散两物体相对运动能量；同体降低摆动 | 阻尼降低动能 |
| 09 | 快子光矛 | 朝向射线耗电，损伤最近命中位置 | 方向命中、消耗、限流 |
| 10 | 电磁加速器 | 推出指定物体/货舱，自身得到反冲 | 抛物与动量守恒 |
| 11 | 电弧发射器 | 定向命中，导电连接传播，可伤友方 | 连通导电传播 |
| 12 | 爆破核 | 消耗自身、径向推力/损伤，不分敌我 | 自毁、友伤、障碍冲量 |
| 13 | 装甲板 | 仅覆盖其所在位置，先受碰撞/攻击，耐久尽失效 | 局部损伤、耐久 |
| 14 | 护盾发生器 | 电能抵扣攻击，欠电部分穿透；不挡物理碰撞 | 攻击护盾与碰撞区别 |
| 15 | 诱饵信标 | 只改变依赖信号的追踪敌人选择 | tracker 与普通 turret 差别 |
| 16 | 缩小环 | 目标尺寸 0.2–1 倍，视觉/碰撞同步，质量/能量/强度不改 | 缩放守恒、方向边界 |
| 17 | 放大环 | 目标尺寸 1–3 倍，扩大保护面和碰撞风险，不增加功能强度 | 缩放守恒、方向边界 |
| 18 | 位移器 | 全组件沿预设方向位移；终点须放得下；速度保持 | 全体落点检查、速度守恒 |
| 19 | 分裂核 | 非货物模块独立分裂，均分质量/能源/强度，货物不复制 | 分裂守恒、拒绝复制货物 |
| 20 | 距离探头 | 指定方向最近外部物体，范围内持续信号 | 方向、范围、持续探测 |
| 21 | 碰撞开关 | 仅外部接触触发，不被自身邻接件触发 | 内外接触区分 |
| 22 | 延时器 | 排队延迟输入状态变化 | 延迟上升/下降沿 |
| 23 | 与门 | 两个输入均真才真 | AND 真值 |
| 24 | 或门 | 任一输入真即真 | OR 真值 |
| 25 | 非门 | 输入反相；未接输入视假 | NOT 真值 |

货舱是额外承载对象，不冒充其中任何一个功能零件。多个货舱分摊同一订单的总载荷；必须全部送达，才能成功。

## 明确的实现选择与简化

- 9×5 正交格、90°初始旋转、相邻自动结构连接、下拉框信号/目标选择，是本次操作方案，附件没有指定网格或接线方式。
- 数值单位为 m、kg、s、J；用于游戏手感，不构成真实航天工程模型。
- 模块圆形碰撞体、结构图拆分、简化刚体惯量与应力求解；没有三维纵深碰撞、软体形变或逐三角网格碰撞。
- 发射台是固定设备的有限准备/发射阶段，不是和飞行器同时推进的另一艘船。没有在不支持的发射台部件上提供无效按钮。
- 收件范围依航线为半径 5–6 m 的有限接收区，另有速度门槛；没有复杂自动泊船流程。
- 航线含陨石、狭窄缺口、普通炮台、信号追踪海盗与局部引力场。原文的“怪物”等是候选风险，本版没有额外怪物生态。
- 单机五条可重复航线、少量客户故事、三级计费研究、一个方案槽；没有商业规模的剧情量、科技树或跨设备云存档。
