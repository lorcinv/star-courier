## 实现约束

- 保存车间等级和已开放边界；读旧方案时不静默裁切模块。既有图纸、库存、ID、接线及撤销快照保持有效。
- 固定侧视下向右增加独立绘制的工作间，不能拉伸原店图。新原图位于 source_art/2d_v5/workshop-expansion/right-bay-original.png，必须按实际地板线统一比例注册。
- 编辑区支持平移、缩放和看全船。屏幕→像素画布→世界→网格使用同一逆变换；测试每档边界格、整数缩放、信号选择和缩放中的指针释放。
- 店面镜头和工位镜头分开，扩建房间不把原柜台缩成小图；背景大范围平移不能暴露镜像建筑接缝。
- 机器人根据实际货舱坐标装货，扩建后要有地面通路及可见机械臂；装货仍是一件包裹，不复制库存。
- 大船发射位置由实际外廓和发射台计算，保证不在装置内部生成障碍；没有“漂亮大外壳”替代真实碰撞体。
- 升级扩大装配空间，不承诺任意体型都能通过现有窄门。应明示真实尺寸与路线风险，并逐步提供适合大装置的航线。

## 接受条件

1. 重启保留等级，重复点击或恢复不重复扣费，余额不足不部分升级。
2. 初始 / 两档升级各完成安装、旋转、移除、撤销、图纸重载和所有边界格拾取；不同窗口、缩放、平移下对应一致。
3. 同一大船实际进入发射、稳定模拟和拆分；量化 CPU 步长、身体 / 节点 / 特效上限，不以录屏帧率代替引擎性能。
4. 原生输入演示扩建前后工作区、机器人装货及可操控起飞。新版视觉仍需实际画面复核。
